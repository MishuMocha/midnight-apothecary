VERSION HISTORY
Alpha v0.6.5 (Latest)
  • Smoothed the Order 4-6 difficulty spike — quotas still climb fast, but no longer hit a sudden brick wall right when players have the least upgrades.
  • Click power upgrades get a little cheaper to purchase repeatedly, so active clicking keeps pace with rising quotas.
  • Increased Gold earned from completed orders so early runs can afford enough upgrades heading into the tougher Order 5-6 brews.
  • Round timers are unchanged — the pacing is still just as fast and snappy.
Alpha v0.6.4
  • Fixed missing cauldron particle effects for most relics — ambient effects were only wired to 5 specific relics, so any other Fire/Frost/Arcane/Chaos relic (Ashen Sigil, Phoenix Down, Arcane Conduit, Winter's Grasp, Glacial Core, Cursed Ember, Unstable Brew, Familiar's Whisk, Philosopher's Crucible, Alchemist's Starter) showed nothing.
  • Ambient effects are now driven by a relic's Synergy Tag, so every relic in the game reliably shows a themed effect around the cauldron.
  • Added a new glowing violet orb + twinkle effect for Arcane relics.
Alpha v0.6.3
  • Shop upgrade buttons, relic "Buy" buttons, and every pause menu button now share the same satisfying hover glow and click-press feedback as the Ingredient Charms.
  • Relic ambient particle effects reworked — flames, frost, sparks, shimmer, and rainbow effects now render as proper bubbles, curling swirls, and drifting smoke wisps instead of flat colored squares.
  • Added a smoky wisp effect that lingers above the cauldron while brewing with the Dragonfire Pepper relic.
Alpha v0.6.2
  • Fixed unresponsive Ingredient Charm buttons (Stir Frenzy, Time Freeze, Golden Droplet) — they were being fully rebuilt every animation frame, which destroyed the button under the player's tap before the click could register.
  • Charm buttons are now built once and updated in place, keeping their event listeners intact.
  • Added a glowing pulse + live countdown on charm buttons while their buff is active, plus clearer hover/press feedback.
  • Badge overlays (count, buff timer) no longer intercept clicks meant for the button underneath.
Alpha v0.6.1
  • Replaced every raw Unicode emoji with unified, retro-styled inline SVG pixel icons for consistent visuals across iOS, Android, Windows, and macOS.
  • Added a shared icon sprite and helper covering currency, synergy tags, relic/consumable art, and pause menu indicators.
  • Icons now tint to match their theme (gold coin, icy frost, fiery ember, arcane violet, chaos crimson).
Alpha v0.6
  • Implemented persistent Save & Load system via browser localStorage (apothecary_save_v1).
  • Auto-saves state on completed orders, shop transactions, upgrade purchases, and every 10s.
  • Restores gold, mana, order level, upgrades, relics, synergies, and charms upon page reload.
  • Added "Reset Progress / New Run" option in Pause Settings menu with confirmation prompt.
Alpha v0.5
  • Rendering performance optimizations specifically tuned for Firefox / Gecko layout engines.
  • Applied strict CSS containment (contain: layout paint style) and pointer-events isolation on particle containers.
  • Upgraded particle animations to hardware-accelerated 3D transforms (translate3d) with will-change hints.
  • Removed expensive paint filters (box-shadows and drop-shadows) from dynamically spawned particles.
  • Throttled tap particle spawning to a single lightweight burst bubble per click.
Alpha v0.4
  • Overhauled Synergy Tags with fixed Set Tier milestones: Fire (2: +30% Click Power, 4: Overheat Surge), Frost (2: +3s Deadline, 4: Chill State), Arcane (2: +25% Passive Mana/sec, 4: Transmutation +50% surplus Gold).
  • Added 5 new relics (Ashen Sigil, Phoenix Down, Glacial Core, Winter's Grasp, Arcane Conduit) so every tiered tag can reach its 4-piece milestone.
  • Synergy badges on the top bar and shop are now interactive — tap or hover to see a retro tooltip with active tiers and the next threshold.
  • Boosted synergy badges now glow with a pulsing amber border once a tier is unlocked.
  • Shop relic cards now show a hint when purchasing will activate or upgrade a Synergy Tier.
Alpha v0.3
  • Added consumable Ingredient Charms (Stir Frenzy, Time Freeze, Golden Droplet) — one-time boosts usable mid-shift.
  • Introduced Corrupted Relics (Cursed Ember, Unstable Brew) — massive power with dangerous drawbacks.
  • Added Synergy Tags ( Fire, Frost, Arcane, Chaos) — collecting multiple relics of the same tag multiplies their passives.
  • Expanded the Apothecary Shop with a dedicated Ingredients section and a live Synergy tracker.
Alpha v0.2
  • Increased font sizes across relic cards, upgrades, and descriptions for desktop readability.
  • Overhauled Order Deadline bar with pure crimson gradients and smooth liquid wave shimmer.
  • Refined pause menu with dedicated version history drawer and build badge.
Alpha v0.1
  • Rebalanced gold economy and quota exponential scaling.
  • Upgraded cauldron visuals to transparent pixel art.
  • Liquid-style animated UI meters for Mana and Deadline.
  • Bubble-based tap particle effects.
  • Added pause menu, settings, and changelog system.
